# Cees Meijs — De Glasfabriek (Officiële Auteurswebsite)

Een premium, responsieve auteurswebsite voor de Nederlandse schrijver **Cees Meijs**, ontworpen rond zijn historische roman **De Glasfabriek**.

---

## 📖 Over het Project
- **Auteur**: Cees Meijs (1953)
- **Boek**: *De Glasfabriek* (Historische roman)
- **Hoofdpersoon**: Peer Verdonk
- **Omvang**: 200 pagina’s (onder voorbehoud van bevestiging)
- **Historische context**: De Brabantse Kempen & de opkomst van Philips en de bouw van de glasfabriek op Strijp S in Eindhoven.
- **Eerdere publicaties van Cees Meijs**: *Het provinciehuis in de steigers*, *Steengoed*, korte verhalen in *Brabants Dagblad* en *Brabeau*.
- **Officiële bestellink**: [https://www.boekenbestellen.nl/boek/de-glasfabriek/80213](https://www.boekenbestellen.nl/boek/de-glasfabriek/80213)
- **Doelgroep**: Liefhebbers van historische romans, Brabantse streekgeschiedenis en industrieel erfgoed.

---

## 🛠️ Technologie
- **React 19** + **TypeScript**
- **Vite 8** (Razendsnelle tooling & geoptimaliseerde static bundle)
- **Tailwind CSS v4** (Modern utility-first styling met literaire ontwerpthema's)
- **Lucide Icons** (Subtiele, consistente vectoriconen)
- **Schema.org JSON-LD** (Geïntegreerde gestructureerde data voor zoekmachines)
